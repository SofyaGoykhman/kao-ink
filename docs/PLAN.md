# План проекта: сайт kaomoji и ASCII-графики

## Продукт

Один сайт, три раздела:

1. **Библиотека** — каталог kaomoji, Unicode-символов и «шрифтов» с поиском, тегами и копированием в один клик.
2. **Генератор** — ASCII-графика из текста (баннеры, рамки) и из изображений (ASCII / Braille / блоки).
3. **Форматтер** — подгонка готового ASCII-рисунка под экран, платформу и ограничения поля ввода.

## Принятые решения

| Вопрос               | Решение                                                                                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| «Шрифты»             | Стилизованный Unicode-текст (𝓼𝓬𝓻𝓲𝓹𝓽, 𝕕𝕠𝕦𝕓𝕝𝕖, ⓒⓘⓡⓒⓛⓔⓓ, ｆｕｌｌｗｉｄｔｈ…) **и** FIGlet-шрифты для ASCII-баннеров. Настоящие woff-шрифты не входят в объём. |
| Языки                | Русский и английский (i18n с первого дня, локализованные URL для SEO).                                                                                      |
| Дизайн               | Минимализм на старте, детальная проработка позже. Дизайн-токены в CSS-переменных, чтобы перекрасить без переписывания.                                      |
| Платформы форматтера | Telegram, Instagram (сторис и посты), Threads.                                                                                                              |
| Бэкенд               | На старте не нужен: полностью статический сайт, бесплатный хостинг. Вопрос бюджета на AI и БД остаётся открытым.                                            |
| Название             | **Kao.ink** (домен kao.ink: доступность и покупка — открытый вопрос).                                                                                       |

## Стек

| Слой      | Выбор                                                 | Почему                                                                                                               |
| --------- | ----------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Фреймворк | **Astro + TypeScript**, интерактив на Preact-островах | Статические SEO-страницы для каталога (`/ru/kaomoji/happy`, `/en/symbols/arrows`), а генераторы работают в браузере. |
| Ядро      | `packages/ascii-core` на чистом TS без UI             | Логика генерации и форматирования тестируется отдельно; потом её можно переиспользовать в API, CLI или расширении.   |
| Данные    | JSON, собирается на этапе билда скриптами из `data/`  | Без БД и сервера.                                                                                                    |
| Хостинг   | Cloudflare Pages (или Vercel)                         | Бесплатно для статики, превью для каждой ветки.                                                                      |
| Тесты     | Vitest (ядро), Playwright (UI)                        |                                                                                                                      |

Структура монорепо (npm workspaces):

```
apps/web/              сайт на Astro
packages/ascii-core/   генерация, форматирование, ширина символов
data/                  сырые источники, лицензии и скрипты сборки
docs/                  план и заметки
```

| Платформа             | Особенности                                                                                                                                                                                                        | Стратегия                                                                                                                                                                                                                       |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## Этапы

### Этап 0. Фундамент

- Скелет монорепо, ESLint/Prettier, Vitest, CI (GitHub Actions), деплой превью.
- Минималистичная база: моноширинная типографика, тёмная и светлая тема, переключатель ru/en.
- Утилита **ширины символов** (East Asian Width / wcwidth, графемные кластеры). Kaomoji полны полноширинных символов `（＾▽＾）`, и без неё выравнивание и форматтер будут врать.

### Этап 1. Хранилище (MVP)

- **Unicode.** Парсер UCD (`UnicodeData.txt`, `Blocks.txt`) и аннотаций CLDR, которые дают названия и ключевые слова на ru и en. Около 150k символов: разбиение по блокам, ленивая подгрузка. Поиск по названию, коду и ключевым словам.
- **Kaomoji.** Собственный корпус:
  - списки с открытыми лицензиями (MIT/CC), лицензии проверяются и фиксируются в `data/`;
  - конструктор из частей (руки, глаза, рот, щёки), ручная курация;
  - теги эмоций и действий на ru и en.
- **Unicode-шрифты.** Таблицы преобразования текста в стили (Mathematical Alphanumeric Symbols, fullwidth, enclosed и другие), с пометкой, где кириллица не поддерживается.
- **FIGlet-шрифты.** Коллекция шрифтов с проверенными лицензиями и предпросмотром.
- UX: копирование кликом, избранное и «недавние» в localStorage, коллекции.

### Этап 2. Генерация ASCII

- **Простая:** текст → FIGlet-баннер, рамки, таблицы, деревья, разделители, конструктор kaomoji.
- **Сложная:** изображение → ASCII в браузере.
  - Режимы: палитра символов по яркости, Braille (2×4 точки на символ), блоки `▀▄█░▒▓`, контуры (edge detection), дизеринг.
  - Цветной вывод (HTML), живое превью, экспорт в txt, png, html.
- **Позже, опционально:** AI-генерация по промпту по схеме промпт → text-to-image модель → image→ASCII. Требует бэкенда и бюджета.

### Этап 3. Форматтер

- Масштабирование по ширине в колонках с ресемплингом по «плотности» символов.
- Обрезка пустых полей, нормализация табов и переводов строк, учёт полноширинных символов.
- Защита от схлопывания пробелов (`U+2800`, неразрывные пробелы), компенсация пропорционального шрифта.
- Пресеты Telegram (обычный текст), Instagram (пост и сторис) и Threads со счётчиком лимита символов.
- Калибровка ширины символов в пропорциональных шрифтах платформ: таблицы ширин глифов для основных системных шрифтов (SF Pro, Roboto и т. д.), чтобы выравнивать рисунок по реальной, а не «колоночной» ширине.
- Превью «как будет выглядеть» в эмуляции целевой платформы, экспорт сторис в PNG 1080×1920.

### Этап 4. Рост (по желанию)

Пользовательские загрузки с модерацией (БД и авторизация), публичный API, PWA/офлайн, расширение браузера, клавиатура kaomoji.
